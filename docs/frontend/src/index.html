Pick a frontend design

Each design is a working tester. Paste any link and it renders at real device widths. Links use the same format as other testers: ?url=…&width=1024&height=600&type=Desktop&scrolling=yes. Use the 1–5 switcher at the bottom left of any design to jump between them with the same link.

01

Split Compare

lighttwo links

Put the current site and the new version next to each other on the same device. Ideal for showing a client before and after a redesign, or live against staging.

  • Side by side, or one Swipe view with a drag handle
  • Name each side (Live, Staging…) and swap them
  • One device picker drives both sides

Breakpoint Strip

lightdevelopers

The same page at every breakpoint width, side by side and frameless, so you see exactly where the layout changes. Labelled with Tailwind's breakpoint names.
